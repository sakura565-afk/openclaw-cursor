# Scene Integrity Gate

Детектор резкой смены плана в сгенерированном клипе. Он отклоняет монтажный скачок в макроплан, но не наезд камеры с непрерывным изменением масштаба. Номера кадров в отчёте — zero-based: событие `frame=112` означает переход 111 → 112.

## Запуск

Из корня репозитория:

```bash
python -m scripts.scene_integrity_gate.cli --video input.mp4 --json report.json
```

CLI возвращает код 0 после успешного анализа независимо от `accept`/`reject`; решение находится в JSON и печатается в stdout. Ошибка декодирования — код 2 argparse.

Python API:

```python
from scripts.scene_integrity_gate import analyze_video
report = analyze_video("input.mp4")
```

## Что измеряется

Каждый кадр уменьшается до 160×160. Для соседних кадров считаются:

- `histogram_distance`: Bhattacharyya distance между 16×8×8 HSV-гистограммами;
- `edge_distance`: Dice distance между Canny-картами после допуска 3×3, то есть изменение структуры, а не только яркости;
- `skin_jump`: модуль изменения доли кожи по YCrCb/HSV-маске;
- `context_drop`: потеря доли пикселей с цветами не-кожи первого кадра — совместная модель одежды и фона референса;
- `object_drop`: потеря поддержки характерных объектов сцены. Для этого сравниваются цветовые сигнатуры содержащих края и не-кожу ячеек сетки 4×4 первого кадра;
- `abruptness`: `scene_score / max(local_baseline, 0.03)`, где baseline — медиана соседних переходов вне окна ±1 кадра.

`scene_score = 0.45*histogram_distance + 0.35*edge_distance + 0.20*skin_jump`.

### Правила reject

`abrupt_scene_change`, если одновременно:

1. `scene_score >= 0.32`;
2. `histogram_distance >= 0.22`;
3. `edge_distance >= 0.38` **или** `skin_jump >= 0.12`;
4. `abruptness >= 2.5`.

`figure_disappeared`, если одновременно:

1. `skin_jump >= 0.12`;
2. `context_drop >= 0.15`;
3. `object_drop >= 0.18`;
4. `abruptness >= 2.5`.

События одного типа ближе трёх кадров объединяются, поэтому переход за 1–3 кадра даёт один повод отклонения. Для каждого повода JSON содержит кадр, величину скачка, порог и все исходные метрики.

Наезд не отклоняется только из-за суммарного изменения масштаба: гейт смотрит на локальный скачок между соседними кадрами. На синтетическом зуме 1.0→2.4× максимум `skin_jump` был 0.0118, `histogram_distance` — 0.1614, клип принят и классифицирован как `smooth_zoom`. На жёсткой склейке тех же сцен `scene_score=0.9850`, клип отклонён. Трёхкадровый переход также отклонён тестом.

## Обоснование порогов корпусом

- Среди пяти принятых реальных клипов максимальный `scene_score` — **0.2756** (CHEF_A_NOANAT), среди одиннадцати отклонённых минимальный пик — **0.4114** (CHEF_ANAT); отдельное самое слабое reject-событие — **0.4091**. Порог **0.32** разделяет эти группы и находится выше максимума синтетического зума 0.2962.
- Максимум гистограммного расстояния среди принятых — **0.2089**; минимум на reject-событиях — **0.2731**. Порог **0.22** лежит между ними.
- Максимум `skin_jump` среди принятых — **0.0691**, у reject-событий `figure_disappeared` — от **0.1824** до **0.8643**. Порог **0.12** консервативно ниже наблюдаемых разрывов.
- `edge_distance` само по себе не используется: у плавного движения края тоже меняются. Значение **0.38** — лишь поддерживающее условие при уже большом скачке цвета.
- `context_drop >= 0.15` отделяет исчезновение референсной одежды/фона: у принятых максимум **0.0125**, у reject-событий `figure_disappeared` — от **0.2582** до **0.8520**.
- `object_drop >= 0.18` применяется только вместе со скачком кожи и контекста. По отдельности объектная сигнатура менее стабильна: у CHEF_B_ANAT обычное начальное движение дало 0.2601 без смены сцены.
- `abruptness >= 2.5` — дополнительная защита от распределённого изменения, а не самостоятельный признак. CHEF_A_NOANAT имеет локальный выброс 6.60, но не проходит абсолютные пороги и правильно принят.

Это пороги текущего H3/17.5M-корпуса, не универсальные константы для других моделей и освещения.

### Расхождения с поставленными метками vision

Формально против исходных меток «хороший/разрыв» совпали 4 из 7: CHEF_A_NOANAT, CHEF_B_ANAT, CHEF_SMALL, CHEF_REF2VA. Три расхождения не были скрыты подгонкой порогов:

- CHEF_PHOTO: независимый просмотр 39/40/41 подтвердил мгновенный переход кухня+фигура → макро на 40; гейт также нашёл обратный переход на 111 и новый макро-переход на 138;
- CHEF_MID: просмотр 67/68/69 подтвердил жёсткую склейку на 68;
- CHEF_WIDE: просмотр 116/117/118 подтвердил жёсткую склейку на 117.

Следовательно, исходные «хорошие» вердикты описывают общее качество/анатомию, а не отсутствие разрыва непрерывности. После уточнения scene-integrity меток по этим кадрам все 7 размеченных клипов классифицируются согласованно. Для девяти клипов без vision-разметки результаты являются предсказаниями гейта, а не подтверждённой человеком разметкой.
