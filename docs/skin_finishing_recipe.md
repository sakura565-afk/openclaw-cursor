# Ретушь кожи: финальный рецепт (2026-11-02)

Полный конвейер, который дал лучший результат по 1:1 QC. Каждый шаг проверен отдельным
A/B-срезом; приведённые параметры — выигравшие значения, не дефолты.

## Почему вообще пришлось этим заниматься

Qwen-Image-Edit рисует кожу как идеально гладкие градиенты. Unsharp такие градиенты не
лечит: `I + amount*(I - blur(I))` только усиливает УЖЕ существующие высокие частоты, а пор
модель стёрла. Значит текстуру нужно ДОБАВЛЯТЬ, а не усиливать.

## Порядок (экспертный, по ресёрчу Kimi - см. skin_expert_research.md)

`Qwen-Edit -> ReActor -> цветокоррекция -> BC_SkinTexture (поры) -> v2-финиш (graft+OKLab+D&B+grain)`

Зерно - всегда ПОСЛЕДНИМ (texture -> upscale -> grain last, BCNodes).

## Шаги

### 1. ReActor - вернуть лицо
denoise 1.0 перегенерирует лицо вместе с одеждой. ReActor (inswapper_128.onnx, HF
`ezioruan/inswapper_128.onnx`; Gourieff/ComfyUI-ReActor отдаёт 401) переносит лицо из
исходной фотографии. ОБЯЗАТЕЛЬНО передавать `source_image` (опциональный вход); без него
нода молча отдаёт исходник (0 изменённых пикселей) - всегда проверять diff.

### 2. Цветокоррекция (skin_grade.py)
YCbCr-маска по тону кожи; внутри маски тепло/насыщенность/микроконтраст.
`--face-a pre.png --face-b post.png` добавляет в маску область лица (diff pre/post ReActor) -
иначе вставленное лицо светится на тёплом теле.

### 3. BC_SkinTexture (BCNodes) - синтетические поры
- Ставится в `ComfyUI/custom_nodes/ComfyUI-BCNodes`; зависимости: `postfx`, `caption-audit`.
- `sam3_model` - любой валидный элемент списка (например `sam3.1_multiplex_fp16.safetensors`),
  но при ПОДКЛЮЧЁННОЙ маске SAM 3 не грузится вообще.
- Параметры: `texture` 1.0 = ±6% яркости -> практический диапазон 0.1-0.3, выигрывает
  **0.10** (0.30 читается как «грязь/перец»); `detail` 0.45; `pore_scale` 1.0; `feather` 8.
- Свою маску кожи берём из `skin_detail_shade.skin_mask` (>0.45) -> PNG -> ImageToMask(red).
- Скрипт: `scripts/bc_skin_texture.py`.

### 4. v2-финиш (skin_retouch_v2.py) - по ресёрчу
1. **Texture grafting**: высокочастотный слой из РЕАЛЬНОЙ кожи (доноры: макро пор
   `Поры на лице человека.jpg` с Commons, `Human skin close-up.jpg`, лицо из исходного фото),
   нарезанный патчами 96 px со СЛУЧАЙНЫМИ поворотами/отражениями и feathered cross-fade.
   Патчи, а не тайлинг, - единственный способ убрать «штамп». Побеждает **donor-amount 0.014**
   (0.022 -> «песок»).
2. **Dodge & burn** - как маленькая карта экспозиции: `Y *= 2**d`, d ограничено ±0.05 EV и
   сильно размыто (σ 40 px). Сильный local-contrast даёт «пластик».
3. **OKLab + частичный Reinhard** - цвет считаем в OKLab, адаптируем **a,b** к РЕФЕРЕНСУ
   (реальное лицо из исходной фотографии) с λ=**0.25**; L не трогаем (полное выравнивание
   яркости стирает форму). ВАЖНО: адаптация к собственным статистикам кадра - no-op, отсюда
   остаточная пятнистость тона. Два случайных низкочастотных поля (σ 90 px, амплитуда
   0.0014) в a и b возвращают естественную цветовую вариативность.
4. **Specular breakup** - в бликах (top 5-15% по яркости) только 30% текстуры.
5. **Зерно последним** - глобальное монохромное, Gaussian, blur 0.5 px, std **0.005**,
   в светах ×0.3.

### 5. Маска кожи - важная деталь
После тёплой цветокоррекции кожа уходит в оранжевый (r-g ≈ 0.26, g-b ≈ 0.23), а серая
ткань/фон имеют r-g ≈ 0.00. Разделитель - именно **r-g**. Строгая маска skin_grade.py на
таком кадре ловила 5% пикселей и резала тёплую кожу; расширенная (skin_detail_shade.py)
ловит ~13-17%. Частотную обработку применять ТОЛЬКО по маске: по всему кадру ткань
превращалась в «хрустящий» рельеф.

### 6. Кроп чёрных полей
Qwen-Edit рендерит фигуру с полями (до 39% кадра - чёрные). Пользователь выбрал кадр
**после кропа** по контентному bbox (AR сохраняется: 0.669 против 0.666 оригинала).

## Проверенные оценки полного конвейера (vision, полный кадр)

| база + цепочка | оценка |
|---|---|
| 2511 + URP_10 (denoise 1.0, cfg 2.0) -> кроп -> ReActor -> грейд -> BC 0.10 -> v2 | **8/10** |
| 2509 + URP_10 -> та же цепочка | 6/10 |
| 2509 + URP_10 + ручной инпейнт кисти у бедра | 4/10 |
| 2511 + URP_20 @ denoise 0.94 -> та же цепочка | 5/10 (зерно крупное, gritty/pebbly) |
| 2511 + URP_10 @ denoise 1.0 без цепочки (сырой) | 6/10 |

Цепочка даёт **+2...+3 балла** к сырому рендеру. URP_20 и denoise<1.0 портят кожу.
Оптимум - **URP_10 при denoise 1.0 на 2511**.

## Что НЕ работает (проверено, не тратить время)

- **Luminance-перенос текстуры** (skin_texture_transfer.py): складки референса читаются как
  царапины, поры-как-кольца - как штамп. Base лучше.
- **Normal-map перенос** (skin_detail_shade.py): рельеф донора переносится корректно, но
  морфология макро-фото (кольца, складки) не похожа на поры. Base лучше.
- **Z-Image detail-pass**: даёт чуть резкости, пор не даёт, ткань фона портит.
  Официальный bf16 грузится; unsloth-fp8 - нет ("Could not detect model type"),
  конвертация через z_image_convert_original_to_comfy.py теряет cap_embedder.1.weight.
- **Skin-LoRA (qwen-edit-skin, URP, HRP)**: fuzz/щетина/грязь.
- **cfg 3-4**: пор не добавляют.
- **masked inpaint для создания кисти**: Qwen выдаёт серую кашу. Механизм рабочий (вне маски
  всё сохраняется), но новые части тела он не генерит. Годится для УДАЛЕНИЯ артефакта
  (лишняя кисть из-за бедра) - но результат кадрозависим.

## Итог

Пор в натуральном виде добиться не удалось ни одной моделью. Реалистичность (4-8/10)
упирается не в цвет, а в саму генерацию: пластичное тело и «мятая бумага» вместо ткани.
Цветокоррекция и ретушь кожи дают локальное улучшение 1:1-срезов, но не переводят
картинку в «фотографию». Следующий рубеж - перегенерация тела другим бэкендом
(Impact Pack detailer @ denoise 0.3 или Flux/SDXL-refiner по рецепту из ресёрча).
