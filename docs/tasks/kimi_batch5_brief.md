# Задача 2 - `scripts/scene_integrity_gate/`: ловить макро-разрыв

**Зачем.** Половина наших роликов портится резким переходом в макроплан промежности
между кадрами ~90 и ~140. Это ловится автоматически и должно быть гейтом.

**Что сделать.** Пакет `scripts/scene_integrity_gate/`:
1. **Детектор смены сцены** по клипу: между кадрами сравнивай (а) глобальную
   цветовую гистограмму, (б) карту краёв/структуры, (в) долю кадра, занятого
   кожей. Резкий скачок = разрыв. Обязательно отличай **наезд камеры** (плавный
   рост детализации) от **смены сцены** (скачок метрики за 1-3 кадра).
2. **Детектор «смена плана»: фигура исчезла** - по доле площади, занимаемой
   одеждой/фоном референса, и по наличию в кадре характерных объектов сцены.
3. **Гейт пригодности клипа**: accept/reject + конкретные причины (номер кадра,
   метрика, величина скачка). Пороги обосновать числами по нашему корпусу.
4. **Разметка нашего корпуса**: прогони гейт по всем рендерам из
   `G:/hermes_archives/renders/` и сведи с известными вердиктами vision
   (CHEF_PHOTO, CHEF_MID, CHEF_WIDE, CHEF_A_NOANAT, CHEF_B_ANAT - хорошие;
   CHEF_SMALL, CHEF_REF2VA - с разрывом). Приложи таблицу "предсказание гейта vs
   вердикт vision" - расхождения разбери и исправь.
5. **CLI** `scripts/scene_integrity_gate/cli.py --video <mp4> --json out.json`.
6. **Юнит-тесты на синтетике**: склейка двух разных сцен = reject; плавный наезд =
   accept; ровная сцена = accept.

**Приёмка.** Гейт верно классифицирует наш размеченный корпус (приложи таблицу);
